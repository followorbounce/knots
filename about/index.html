How this guide is made

Knot Atlas teaches 75 knots so far, each one drawn from a 3D model of the rope rather than from photographs.

The rope models

Each knot is described as one or more ropes: a smooth centreline through a set of control points, with a rope thickness. Knots tied in the flat are described as a drawing plus a code that says, at each crossing, which strand goes over. Knots tied round a post, a ring or another rope are modelled directly in 3D.

Before a knot is published a checker runs on the model. It confirms that no part of the rope passes through another part, through another rope, or through the post or ring, and that the number of crossings matches the knot’s code. The step-by-step view reveals the rope in the order you tie it, and the over and under tags are read from the model at each crossing the moving end makes.

What the drawings show

The models show knots loosely, so you can see the path of the rope. A real knot drawn tight looks more compact. Mirror shows the mirror-image knot, which is the same knot tied with the other hand. Every flat diagram is a projection of the same model.

Safety

Knots used to hold people need training. Learn life-safety knots from a qualified instructor, and have a partner check every one before it is loaded. Nothing on this site replaces training, manufacturer instructions or local rules for climbing, rescue, lifting or boating.

Credits

3D rendering uses three.js. Type is set in Barlow Condensed and IBM Plex. Knot names are the common names used by sailors, climbers and anglers; where a knot has several names, the others are listed under its title.
