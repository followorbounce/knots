# Knot Atlas

Static site, generated by `python3 build.py`. Never hand-edit generated HTML
(`index.html`, `knots/`, `basics/`, `finder/`, `about/`, sitemap/robots/llms.txt).

## How a knot is made
1. Model in `geometry.py`: a function returning ropes (control points), optional
   `code` (over/under letters, one per crossing, read in traversal order: rope 0
   first, then rope 1; first visit of each crossing consumes a letter), objects
   (pole/ring), and `marks` (named control-point indices the steps reveal up to).
   Knots on objects are modelled in explicit 3D with `coil_y` / `coil_x` helpers.
2. Preview: `python3 tools/preview.py <geometry_fn> <outdir>` → PNG with numbered
   crossings plus a top view. Look at it before trusting a model.
3. Content in `knots.py` (steps reference marks). Step captions must match the
   tags the model produces: check with the tag dump snippet in progress.md.
4. `python3 build.py` runs the checker (rope/rope, rope/object clearance, crossing
   count vs code, and knot type via Jones polynomial where the knot has `expect`
   and the geometry has `closure`). Problems print as warnings; do not publish with warnings.
5. A clean checker is not proof of the right knot: the wave-1 Square Knot passed
   clearance but was topologically wrong. Give every knot that closes to a known
   type an `expect`, and compare tags per step with the captions.

## Conventions
- All text is original. Do not name or cite the reference book used for the knot
  syllabus anywhere in the project (code, docs, commits). The reference PDF lives
  outside the repo and is never committed.
- Rope colours: a = yellow (ochre), b = blue (teal), c = red (rust). Captions call
  them yellow/blue/red.
- English only. iPhone rules: 44px targets, 16px inputs, safe areas.
- three.js r128 from cdnjs + OrbitControls from jsDelivr, pinned.
- Headless Firefox screenshots do not capture WebGL. To check a 3D render, copy
  the canvas into an <img> via toDataURL in a throwaway page (see progress.md).

## Feed (homepage widget removed)
`build.py` still writes `feed/index.json` and `feed/<slug>.json`. The followorbounce.github.io
"Knot of the day" plugin that read them was removed from the homepage on 2026-10-14 at the
owner's request (its engine files are kept there, unused).
